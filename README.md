# nest-next-cli

CLI de scaffolding para proyectos NestJS + Prisma, Next.js o monorepo, listos para producción desde el primer commit.

Ver [`PLAN.md`](./PLAN.md) para el plan completo (alcance, stack, milestones y estrategia de versionado de templates).

## Desarrollo

```bash
pnpm install
pnpm dev      # ejecuta el CLI en modo desarrollo (tsx)
pnpm build    # build de producción con tsup
pnpm test     # corre la suite de Vitest
pnpm lint     # ESLint
```
